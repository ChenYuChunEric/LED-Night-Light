# LED 夜燈 (LED Night Light)

這是一個具備充電功能的 LED 夜燈專案。採用 TP4056 鋰電池充電管理晶片與 SDB628 升壓轉換晶片，支援透過 USB Type-C 進行充電，並提供穩定的電力輸出給 LED 燈源。

## 專案特點

- **Type-C 充電介面**：支援現代化的 USB Type-C 輸入。
- **鋰電池管理**：使用 TP4056 進行安全可靠的鋰電池充電管理。
- **升壓轉換**：透過 SDB628 升壓電路，確保電池電壓在變動時仍能提供穩定的亮度。
- **指示燈功能**：內建紅燈與藍燈，分別顯示充電中與充電完成狀態。
- **完整 3D 模型**：包含外殼（底座與上蓋）的 STL 檔案，可直接進行 3D 列印。
- **製造準備**：提供完整的 Gerber 檔案與 BOM 表，方便進行 PCB 製作與零件採購。

## 目錄結構

- `3D_PCB_TP4056.SDB628_2023-01-24.stl`: PCB 的 3D 模型。
- `BOM_PCB_TP4056.SDB628_2023-11-26.csv`: 零件清單 (Bill of Materials)。
- `Gerber_PCB_TP4056.SDB628.zip`: PCB 製造所需的 Gerber 檔案。
- `PCB正面.png` / `PCB反面.png`: PCB 的視覺化圖檔。
- `原理圖.png`: 電路設計圖。
- `上蓋.stl` / `底座.stl`: 夜燈外殼的 3D 列印模型。

## 主要零件清單 (BOM)

| 零件類型 | 型號/規格 | 數量 | 說明 |
| :--- | :--- | :--- | :--- |
| 充電 IC | TP4056 | 1 | 鋰電池充電管理 |
| 升壓 IC | SDB628 | 1 | DC-DC 升壓轉換 |
| 輸入接口 | USB Type-C | 1 | 電力輸入 |
| 電感 | 22uH | 1 | 升壓電路必備 |
| 二極體 | SS34FL | 1 | 蕭特基二極體 |
| 指示燈 | 3mm LED (紅/藍) | 各 1 | 充電狀態顯示 |
| 連接器 | XH2.54-2P | 2 | 用於連接電池與 LED 燈板 |

## 如何開始

1. **PCB 製作**：將 `Gerber_PCB_TP4056.SDB628.zip` 上傳至 PCB 製造商（如 JLCPCB, PCBWay 等）。
2. **零件採購**：依照 `BOM_PCB_TP4056.SDB628_2023-11-26.csv` 的清單採購所需電子零件。
3. **外殼列印**：使用 3D 列印機列印 `上蓋.stl` 與 `底座.stl`。
4. **組裝**：焊接電子零件至 PCB，連接鋰電池與 LED 燈板，最後裝入 3D 列印的外殼中。
